# Snowflake - one key macropad

<img width="849" height="545" alt="image" src="https://github.com/user-attachments/assets/1c94f477-2876-4bae-8eab-7fdb83358d6a" />

Snowflake is a one key macropad! Solder on any mx-style switch and use it as a one key keyboard - the PCB itself measures 19x19mm :D

Featuring: 

- CH552E as the microcontroller
- Neopixel on the bottom
- All unused pins broken out
- USB-C for power and data
- Keychain hole (M2 screw size); hang it on your bag!

This project was made in ~5h in one go, art included.

<img width="879" height="309" alt="image" src="https://github.com/user-attachments/assets/561cbe62-c916-44b8-99ba-4f66f59be71c" />
